# Milestone 1
- Pressing enter submit form
- Form validation on blur by changing border color to red
- When form is invalid, the password field is cleared and auto-focused.
- Error popup can stack on top of each other.
- Error popup automatically remove itself after 3 seconds.

# Milestone 2
- List of channels get updated when you edit or add channel
- If no channel selected show a screen that prompt the user to select a channel
- Long channel name on sidebar make it truncate into ellipses
- Form validation for create and edit channel fields, causing red outline if
invalid and disable submit button.
- Description textarea for both add and edit scale vertically base on the text inside it
- Editing channel fill the fields with current content.
- Editing channel submit button only get enabled if you edit one of the filed
- The channel detail public/private change icon base on whether it is public or
  private.
- The channel detail show the creator name, email, and profile image. The
profile is also clickable.
- If you don't have an access to channel show appropriate screen with join
button.

# Milestone 3
- Message time/date sent get updated after every 5 seconds
- Pinning message update pinned dashboard in realtime
- Message interaction box showup when you hover over the message. On touch 
devices, it show up on tap on touch devices.
- Reacting to message make create a react label for said message which can be
  use when other user want to react as well
- Message input allow you to enter nextline if you press shift+enter.
- Message input scale vertically base on content up to a point.
- New messages get scroll onto screen.
- Editing message autofocus onto message input
- Cancel editing message by pressing the x or press escape

# Milestone 4
- Invite user modal show the channel name in title
- Invite user modal show user info (profile image, name, email). The entire
  profile is interactable not just the checkbox.
- Editing user profile show current name email, and bio in fields.
- Editing user profile do form validation.
- The submit button only gets enabled if it is changed
- Uploading a new profile image show a preview

# Milestone 5
- When viewing images in modal, you can use the arrow keys to naviage to
next/previous images.
- Uploading images show preview and a way to cancel
- You can edit messages with image by uploading a new image or turn it to a text
  message instead

# Other
- All form focus next input based on tab, the label is properly associated with
  input, and you can press enter to submit form.
- All modal can be cancel by pressing escape
- Both the pinned message dashboard and sidebar is collapsable.
- Pinned message dashboard and sidebar collapse by default on small screen.
- The button on header became small on small screen
- Add channel, edit channel, and logout button show title when hover
- All images has alt text.
